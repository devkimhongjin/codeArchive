# GitHub 결과 대조

과거 풀이 GitHub 일괄 커밋에서 `결과 확인 필요` 제출의 **GitHub 결과 대조**를 실행합니다.

- 서버는 로그인 계정의 제출만 확인합니다. 작업을 시작할 때 계정·설정 세대·대상·경로·출력 내용의 SHA-256을 저장하며 원본 코드나 GitHub 응답·인증 정보는 진단에 저장하지 않습니다.
- 원래 설정과 출력이 유지되는 경우 설치 권한을 다시 확인하고 해당 브랜치의 한 커밋에 고정해 파일을 읽습니다. KST와 이전 UTC 경로의 정확한 내용 일치를 확인하면 완료로 복구합니다. 저장소 파일이나 브랜치는 변경하지 않습니다.
- 파일이 없거나 다른 내용이거나 응답을 확인하지 못하면 `UNKNOWN`을 유지합니다.
- 브랜치 갱신 전에 중단됐다는 진단이 있는 수동 작업에 한해 **대조 후 재시도 요청**이 표시됩니다. 재시도 때 다시 대조하고 설정·작업 상태를 검증한 후 요청을 접수합니다. 갱신 응답 유실·만료·예외는 재시도 대상이 아닙니다.
- 이전 버전에서 생성된 작업은 원래 출력 기록이 없으므로 대상을 추측하지 않습니다. 해당 제출의 실제 결과 검증은 별도로 필요합니다.
