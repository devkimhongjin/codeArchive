# 프로젝트 운영 문서

이 디렉터리는 CodeArchive의 실행 가능한 프로젝트 상태와 운영 기록을 관리한다.

## 문서 역할

- `roadmap.md`: 제안서의 개발 단계를 실행 가능한 마일스톤으로 관리
- `backlog.md`: `TASK-####` 단위 작업과 우선순위 관리
- `kpi.md`: 성공 기준, 측정 방법, 기준값과 결과 기록
- `tech-stack.md`: 기술 스택, 버전 근거와 선택 이유 기록
- `troubleshooting.md`: 증상, 원인, 해결 방법과 예방 조치 기록
- `decision-log.md`: 변경 요청과 운영 결정을 간략히 기록

중요한 구조, 데이터, 보안, 외부 연동 결정은 `docs/adr`에 별도 ADR로 남긴다.
