# CodeArchive Extension v1.0.3

## 변경 사항

- 업데이트·재활성화·Chrome 시작 뒤 기존 서버 로그인 쿠키로 계정과 자동 동기화 연결을 다시 확인합니다. 유효한 연결은 재사용하고, 만료된 연결은 동일한 로그인 계정에서만 복원합니다.
- 일시적인 서버 연결 오류로 저장된 연결을 지우거나 서버의 연결 권한을 철회하지 않도록 수정했습니다.
- 문제 제출 시 자동 동기화 연결을 확인하고, 로그인 필요·서버 통신 실패·계정 변경을 문제 화면에서 안내합니다. 대시보드 열기와 연결 재확인 버튼을 제공합니다.
- 사이트의 제출 동작을 방해하지 않으며, 서버 등록에 실패한 정답 풀이는 동기화 완료로 표시하지 않습니다.

## 업데이트 안내

서버에서 실제로 만료되거나 로그아웃된 세션은 GitHub 재로그인이 필요합니다. 쿠키나 인증 정보를 복사해 강제로 복원하지 않습니다. 이전 버전의 다운로드 권한 승인으로 확장이 비활성화된 경우 다시 활성화해 주세요. 확장 갱신 전에 열린 문제 탭에는 새로고침 안내가 표시될 수 있으며, 작성한 코드를 확인한 뒤 새로고침해 주세요.

심사 중인 1.0.2를 변경하지 않고 다음 버전으로 준비합니다. 자동 배포 예약과 릴리스 태그의 웹스토어 자동 제출을 취소했습니다. 수동 실행은 기본적으로 업로드 없는 검증이며, 이 버전의 실제 게시와 스토어 업데이트 검증은 별도로 진행합니다.
