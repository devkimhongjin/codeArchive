# CodeArchive Extension v1.0.10

## 변경 사항

### 같은 문제를 다시 맞혔을 때 자동 커밋 여부 선택 (#510)
- 같은 문제를 같은 언어로 다시 맞히면 자동 커밋이 매번 새 파일을 만들어 저장소에 중복이 쌓였습니다. 이제 다음 중에서 고를 수 있습니다.
  - **맞힐 때마다 커밋**(기본값, 지금과 같음)
  - **처음 맞힌 제출만 커밋**
- 설정 위치
  - 팝업: GitHub 자동 커밋 스위치 아래 "같은 문제는 처음 맞힌 제출만 커밋" 체크박스. 자동 커밋이 켜져 있을 때만 보입니다.
  - 대시보드: GitHub 관리 → GitHub 자동 커밋 카드의 "같은 문제를 다시 맞혔을 때"
- 커밋하지 않은 제출도 서버에는 저장되고, 일괄 커밋으로 직접 올릴 수 있습니다. 다른 언어로 푼 풀이는 따로 커밋됩니다.
- 이전 커밋이 실패했다면 GitHub에 아무것도 올라가지 않았으므로 다음 정답을 커밋합니다. 결과를 모르는 커밋은 올라갔을 수 있어 같은 문제로 봅니다.
- 직접 고르는 일괄 커밋에는 적용하지 않습니다.

## 서버 (확장보다 먼저 배포)
- 설정 저장과 자동 커밋 판단(DB V33 열 추가, 기본값은 지금과 같음)을 2026-11-10에 배포했습니다.
- 스테이징 DB 정책을 읽기 전용 점검 결과로 갱신하는 절차를 추가했습니다(#511, #512). 사용자 동작과는 관계없습니다.

## 업데이트 안내
- 이번 버전은 권한을 바꾸지 않습니다. `manifest.json`의 권한과 접속 허용 사이트는 1.0.9와 같습니다. 기존 로그인, GitHub 연결, 자동 커밋 설정은 그대로 유지됩니다.
- 팝업에서 체크박스를 바꾸면 자동 커밋 스위치와 같이 서버 설정을 저장하고 자동 동기화 연결을 새로 받습니다.

## 알려진 한계
- 팝업 높이는 실제 렌더링 코드를 헤드리스 Chrome으로 잰 값입니다(최대 440px).
- "처음 맞힌 제출만 커밋"으로 실제 재제출이 커밋되지 않는지는 스토어 설치본에서 [#456](https://github.com/devkimhongjin/codeArchive/issues/456)으로 확인합니다.

## 배포 절차
- `DEFAULT_PUBLISH`로 심사를 제출합니다. 심사를 통과하면 바로 공개됩니다.
