# CodeArchive Extension v0.3.3

## 변경사항

- 사용자 제거 지시(#422)에 따라 로컬 정적 분석 UI, 분석 worker·client·계약과 전용 파서 의존성을 제거했습니다. 단순히 UI를 숨기는 변경이 아닙니다.
- 풀이 수집·로컬 보관·검색·코드 테마·복사·다운로드와 로그인·동기화·GitHub 기능은 유지합니다.
- 개인정보 안내와 스토어 설명에서 분석 기능 소개를 제거합니다. 이전 분석 홍보 캡처는 재사용하지 않습니다.
- 제출 ZIP은 개발용 manifest.key를 포함하지 않습니다(#420/#421).

## 범위와 출시 상태

관련 #250/#400/#422. API·DB·서버 정책, 확장 ID, 권한과 허용 origin을 변경하지 않습니다. 풀이 및 기존 브라우저 캐시는 삭제하지 않습니다. 이전 분석 결과는 더 이상 사용하지 않습니다.

이 브랜치의 ZIP은 사용자 요청에 따른 교체 후보이며, develop → master 승격이나 실제 업로드·심사·게시는 별도 승인·검증 대상입니다. 기존 실제 스토어 ID의 OAuth 복귀/CORS 및 서버 문의 정책 적용 검증을 통과한 것으로 바꾸지 않습니다.
