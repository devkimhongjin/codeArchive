# CodeArchive Extension v0.2.3

## 변경사항

- 복사·다운로드·GitHub 코드 주석의 풀이 시각을 한국 시간(KST)으로 표시하도록 수정했습니다.
- 로컬 보관함, 과거 수집 제출 시각 및 릴리스 날짜 표시도 한국 시간 기준으로 통일했습니다.
- 기존에 저장된 제출 시각은 변경하지 않고 표시할 때 변환합니다.

## 업데이트 안내

ZIP 내용을 기존 설치 폴더에 덮어쓴 뒤 Chrome 확장 관리에서 새로고침하세요. 로컬 풀이를 유지하려면 확장을 삭제하지 마세요. 이미 열린 문제 탭은 코드를 확인한 뒤 새로고침해야 새 수집 스크립트가 적용됩니다.
