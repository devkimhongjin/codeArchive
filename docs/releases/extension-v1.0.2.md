# CodeArchive Extension v1.0.2

## 변경 사항

- 대시보드를 열 때 서버 연결·로그인 확인 상태를 팝업으로 표시합니다. 연결 중에 로그아웃되거나 전체 풀이가 없는 것처럼 보이던 혼동을 줄였습니다.
- GitHub 로그인이 필요한 경우 같은 팝업에서 로그인을 시작할 수 있습니다. 팝업은 연결·계정·풀이 목록 확인이 완료되면 자동으로 닫힙니다.
- 프로그래머스의 정확성 테스트와 효율성 테스트 결과 표가 나뉜 문제에서도 실행시간과 메모리를 수집합니다. 전체 테스트의 실행시간 합계와 전체 테스트의 평균 메모리로 집계합니다.
- 제출 전 결과와 비교하여 새 정확성 결과에 이전 효율성 결과가 섞이지 않도록 확인합니다. 기존 단일 결과 표와 동일 코드 재채점 안내도 지원합니다.
- 배포 자동화에 웹스토어 게시·심사 상태의 읽기 전용 확인을 추가했습니다. 이전 버전의 실제 게시를 확인한 뒤 다음 버전을 제출하며 진행 중인 심사를 취소하지 않습니다.

## 업데이트 안내

풀이 등록·조회에는 GitHub 로그인과 CodeArchive 서버 연결이 필요합니다. 통신 실패 시 팝업에 오류와 재시도 방법을 표시합니다.

성능 결과가 불완전하거나 다른 제출의 결과와 구분할 수 없으면 성능 정보는 제외하며 정답 코드 수집은 계속합니다. 이번 변경은 새 제출부터 적용되며 기존 서버 기록을 임의로 수정하지 않습니다.

이 릴리스는 develop에서 통합·검증 후 master 소스로 빌드합니다. 웹스토어 제출 접수 이후에도 심사와 업데이트 전파가 필요합니다. 실제 스토어 확장의 새 제출 수집과 로그인 동작 검증은 관련 이슈에서 별도로 확인합니다.
