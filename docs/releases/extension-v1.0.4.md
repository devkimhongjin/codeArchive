# CodeArchive Extension v1.0.4

## 변경 사항

### 수정
- 오랫동안 확장을 쓰지 않다가 팝업을 열면 GitHub 자동 커밋 토글이 한참 동안 비활성화된 것처럼 보이던 문제를 고쳤습니다. 토글은 서버 응답을 기다리지 않고 기기에 저장된 설정으로 바로 표시합니다. 최근 동기화 목록은 서버 확인 뒤 이어서 갱신합니다. (#464)
- 설정을 확인하는 동안에는 토글을 비활성화 대신 `확인 중` 로딩 표시로 보여 줍니다. (#464)
- 대시보드의 서버 연결·로그인 확인 팝업과 GitHub 대상 확인 화면에서 로딩 아이콘이 회전하지 않던 문제를 고쳤습니다. (#465)

### 디자인 개선 (#466)
- 대시보드 전체의 글자 크기·색상·모서리·간격 기준을 정리했습니다. 가장 작은 글자를 11px로 맞춰, 9~10px로 작게 보이던 안내와 메타 정보가 읽기 쉬워졌습니다.
- 과거 풀이 관리 화면을 다른 화면과 같은 카드 레이아웃으로 바꿨습니다. 저장 안내를 `후보 선택 → 서버 등록 → 일괄 GitHub 커밋` 3단계로 보여 줍니다.
- 확장의 과거 풀이 수집 화면(플랫폼 선택·사이트 내역 열기)을 대시보드와 같은 디자인으로 맞췄습니다.
- GitHub 관리에서 파일명·Git 경로·커밋 메시지 미리보기를 별도 상자로 표시하고, 토큰 버튼을 키웠습니다. 자동 커밋과 일괄 커밋 섹션을 구분해 표시합니다.
- 전체 풀이 목록의 `다른 풀이 보기` 버튼을 덜 눈에 띄게 바꾸고, 마우스를 올리거나 선택한 행에서만 강조합니다. 상세 화면 상단 버튼의 크기를 통일했습니다.
- 좁은 화면에서 전체 풀이 필터를 한 줄로 줄였습니다.
- 비활성·로딩·오류 표시를 통일하고, 연결이 정상일 때는 상단 연결 안내를 작게 표시합니다.
- 확장 팝업을 새 디자인으로 바꿨습니다. 자동화 상태와 최근 문제 수를 배지로 표시하고, GitHub 커밋 결과를 색으로 구분합니다(완료·진행 중·실패). 임시 저장과 오류 안내도 색으로 구분합니다.

## 업데이트 안내

이번 버전은 권한·접속 대상·서버 API를 변경하지 않습니다. 기존 로그인과 GitHub 연결, 자동 커밋 설정은 그대로 유지됩니다. 확장 갱신 전에 열려 있던 문제 탭은 새로고침 안내가 표시될 수 있으니, 작성 중인 코드를 확인한 뒤 새로고침해 주세요.

게시된 1.0.3 다음 업데이트입니다. 웹스토어 제출은 수동으로 진행하며, 심사 제출과 실제 스토어 공개·설치 업데이트 확인은 구분합니다.
