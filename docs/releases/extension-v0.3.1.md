# CodeArchive Extension v0.3.1

## 변경사항

- PC 앱 연결 없이 확장 대시보드에서 전체 풀이·설정·커뮤니티·GitHub 작업을 관리합니다.
- 신규 정답 자동 동기화를 기본 동작으로 통일하고 팝업에는 최근 동기화된 문제를 표시합니다. 연결된 저장소의 GitHub 자동 커밋을 팝업에서 ON/OFF할 수 있습니다.
- 과거 풀이 수집을 과거 풀이 관리에 통합했습니다. 수집 완료 후 선택·원본 검증·저장에 성공한 제출만 일괄 동기화 또는 GitHub 커밋 대상으로 사용합니다. 미동기화 기록은 먼저 동기화하고 커밋 경로를 확인합니다.
- GitHub 완료 표시의 반복 점멸을 줄이고 계정·제출 변경 시 이전 응답을 무효화합니다. 불필요한 연동 가이드 메뉴를 제거했습니다.
- 커뮤니티를 목록·코드 화면으로 정리하고 정렬·좋아요·댓글·중복 제출 공개 설정을 지원합니다. 65개 코드 테마와 설정 미리보기를 제공합니다.
- 과거 제출 누락 대조·원본 확인 후 보강, 난이도 표시, 실행 없는 로컬 정적 분석, UNKNOWN GitHub 결과 대조·안전한 재확인 흐름을 추가했습니다.
- 웹스토어 패키지에서 개발용 localhost 및 사용하지 않는 공개 릴리스 조회 권한, 소스맵을 제외하고 로컬 코드 CSP를 적용합니다.
- 인증된 대시보드에 개인 문의·오류 제보와 관리자 답변을 추가했습니다. 문의에는 사용자가 입력한 분류·제목·메시지만 포함하며 종료 후 90일이 지난 항목은 다음 문의 기능 접근 시 정리됩니다.

## 업데이트와 검증

기존 확장은 삭제하지 말고 사용 중인 폴더의 파일을 교체한 뒤 Chrome에서 새로고침하세요. 열린 대시보드와 사이트 탭도 코드를 확인한 뒤 새로고침합니다. Chrome 종료 중에는 수집·동기화 작업이 실행되지 않습니다.

이 버전은 master에서 생성한 웹스토어 제출 준비 버전입니다. GitHub/스토어 게시, 심사 통과, 실제 스토어 ID의 로그인이나 데이터 이전을 완료했다는 의미는 아닙니다. 최종 ZIP의 실제 화면 검증·스토어 ID·개인정보 운영 절차는 #400에 남습니다. 기존 PC 앱 공개 릴리스와 Netlify 웹 배포를 변경하지 않습니다.
