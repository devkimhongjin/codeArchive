# CodeArchive Extension v1.1.0

## 변경 사항

### 백준(acmicpc.net) 지원 (#515, #517)
- **정답 자동 수집**: 제출 후 이동한 채점 현황에서 그 제출이 `맞았습니다!!`가 되면 코드·언어·시각·시간·메모리를 서버에 등록합니다.
- **과거 풀이 수집**: 로그인한 본인의 정답 목록과 소스 페이지를 백그라운드 탭에서 간격을 두고 열어 등록합니다(목록 3초, 소스 3~5초). 1,000건이면 약 1시간 걸립니다.
- **채점 현황에서 동기화·커밋**: 내 아이디로 조회한 채점 현황의 정답 행마다 버튼이 나옵니다.
- **난이도**: solved.ac 티어(Bronze V~Ruby I)를 표시합니다.
- **로그인 카드**: 백준 페이지를 마지막으로 열었을 때의 로그인 상태를 보여 줍니다.

### 난이도 표시와 주석 옵션 (#519)
- 대시보드의 풀이 목록과 상세에 확인된 난이도를 배지로 표시합니다.
- 복사·다운로드·GitHub 커밋 주석에 `난이도`를 넣을 수 있습니다. 기본은 꺼져 있습니다.

### 정올 난이도 자동 수집 (#521)
- 정올에서 정답을 자동 수집할 때 문제 페이지에 표시된 티어(Bronze V~Ruby I)를 함께 저장합니다. 정올이 자체로 매긴 값이며, 티어가 없는 문제는 비워 둡니다.
- 과거 수집과 제출현황 동기화에는 적용되지 않고, 이미 저장된 풀이는 채우지 않습니다.

## 서버 (확장보다 먼저 배포)
- 백준 플랫폼, solved.ac 난이도 검증, 괄호가 붙은 언어 이름(run 45525139758)과 주석의 난이도 항목(run 45528590821), 정올 난이도 검증(run 45557031738)을 2026-11-25에 배포했습니다.
- V34: 난이도 열을 20자로 늘려 `Platinum III`처럼 긴 티어를 저장합니다.
- 스테이징 DB 정책을 갱신했습니다(#516). 사용자 동작과는 관계없습니다.

## 업데이트 안내
- **권한이 늘어납니다.** `https://acmicpc.net/*`, `https://www.acmicpc.net/*`(백준 제출 확인), `https://solved.ac/*`(백준 난이도)가 추가됩니다. Chrome이 새 권한을 승인할 때까지 확장을 꺼 둘 수 있으니, 꺼져 있으면 확장 관리 화면에서 승인해 주세요.
- solved.ac에는 문제 번호만 보내고 쿠키나 계정 정보는 보내지 않습니다.
- 이전 버전에서 백준 풀이가 서버에 거부되어 남아 있다면 팝업에서 `지금 동기화`를 눌러 주세요.

## 알려진 한계
- 백준은 한국어 화면만 읽습니다.
- 컴퓨터 시계가 백준과 2분 넘게 다르거나, 결과를 보지 않고 같은 길이의 코드를 2분 안에 다시 내면 자동 수집되지 않습니다. 채점 현황의 `동기화`로 등록할 수 있습니다.
- 백준 이용약관은 과도한 자동화 접근을 금지합니다. 과거 수집은 본인 제출에만 필요한 만큼 사용해 주세요.
- 스토어 설치본의 실제 동작은 [#456](https://github.com/devkimhongjin/codeArchive/issues/456)에서 확인합니다.

## 배포 절차
- `DEFAULT_PUBLISH`로 심사를 제출합니다. 심사를 통과하면 바로 공개됩니다.
