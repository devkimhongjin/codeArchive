# CodeArchive Desktop v0.1.1

## 변경사항

- PC 앱과 확장 릴리스 발행을 master 기준으로 제한했습니다. 다른 브랜치의 수동 발행과 master 릴리스 이력 밖의 태그는 거부합니다.
- 서명된 앱 업데이트 정보에 master 출처와 소스 커밋을 포함하고 앱에서 확인합니다.
- 설치된 앱은 시작 시와 6시간마다 새로운 안정 릴리스를 확인합니다. 설정 → PC 앱 설정에서 업데이트 확인과 다운로드·적용을 실행할 수 있습니다.
- 새 버전을 다시 확인할 때 이전 다운로드 대상을 초기화해, 내려간 릴리스를 계속 설치하는 일을 방지했습니다.
- 업데이트 설치 프로그램에 자동 재실행 옵션을 전달하도록 수정했습니다.
- 테스트용 v0.1.0에서 다음 공개 릴리스를 감지할 수 있도록 앱 버전을 v0.1.1로 올렸습니다.

## 포함 기능

Windows 대시보드, 웹브라우저 로그인 후 독립 앱 세션, Chrome 확장 v0.3.0 포함 및 첫 실행 설치·연결 안내, 사용자 지정 아이콘, 설치 완료 화면의 바로가기 선택, 선택형 Windows 자동 시작과 트레이 실행을 포함합니다.

앱 업데이트는 포함된 확장 파일도 갱신합니다. 이후 Chrome 확장 관리에서 새로고침해 주세요. Windows Authenticode 서명과 앱 업데이트 무결성 서명은 별개입니다.
