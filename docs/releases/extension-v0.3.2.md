# CodeArchive Extension v0.3.2

## 변경사항

- 확장에서 시작한 GitHub 로그인과 설치가 끝나면 원래 확장 관리 탭과 창으로 돌아옵니다. 새 브라우저 권한을 요구하지 않습니다.
- 문의·오류 제보를 접수됨/확인중/답변완료 상태형으로 변경했습니다. 채팅식 후속 메시지·임의 종료·삭제와 90일 자동 삭제를 제거했습니다.
- 서버가 확인한 관리자는 작성 화면 없이 전체 문의함으로 바로 진입하고 상태와 단일 답변을 관리합니다.
- 문의·오류 제보 탭을 주 메뉴의 맨 오른쪽으로 옮겼습니다. 기존 문의와 메시지는 보존합니다.

## 적용 순서와 확인 상태

관련 #415/#416/#417. API/V29를 먼저 적용해야 확인중 상태와 자동 삭제 중단이 실제 서버에 반영됩니다. ZIP만 교체해 서버 정책이 바뀌었다고 안내하지 않습니다.

사용자가 2026-10-09 master 승격과 출시 자료 준비를 요청했습니다. 자동 테스트 및 PostgreSQL 검증은 통과했지만 최종 ZIP의 실제 Chrome OAuth 복귀, 관리자/사용자 문의 화면, 실제 스토어 ID/CORS 수용은 아직 미완료입니다. 이 기록은 심사 통과나 게시 완료를 뜻하지 않습니다.

기존 확장을 삭제하지 말고 로컬 데이터를 유지하며 갱신합니다. 로컬 ID와 스토어 ID가 다르면 IndexedDB가 자동 이전된다고 가정하지 않습니다. 외부 서버 배포·스토어 업로드·production 자원 전환은 별도 승인 대상입니다.
