# CodeArchive Extension v1.0.9

## 변경 사항

### 팝업을 간단하게 (#505)
- 팝업을 세로 한 칸으로 정리하고 **최근 동기화된 문제는 1개만** 보여 줍니다. 어떤 상태에서도 스크롤 없이 한 화면에 들어옵니다(이전에는 최근 문제 3개만으로도 Chrome 팝업 최대 높이 600px을 넘었습니다).
- "대시보드 열기"는 머리글 오른쪽으로, "GitHub 자동 커밋" 스위치는 자동화 제목 줄로 옮겼습니다.
- 최근 문제의 "코드 복사"·"다운로드"는 실행 시간 줄 오른쪽에 둡니다.

### GitHub 일괄 커밋 진행 상황은 다시 대시보드에 (#505)
- 일괄 커밋 진행 상황을 팝업 대신 대시보드 맨 위에 보여 줍니다. 처리 건수, 성공·실패·확인 필요 건수, 진행 막대와 "추가 요청 중단"·"작업 이어가기"가 있습니다.
- 진행 중이거나 확인이 필요한 작업은 모든 화면에, 끝난 결과는 GitHub 관리 화면에서만 보입니다.

### 저장소를 연결하면 README에 CodeArchive 배지 (#502)
- 대시보드에서 새 저장소나 브랜치 연결을 저장하면 저장소 README 맨 위(제목 아래)에 `Automated by CodeArchive` 배지와 안내 한 줄을 넣습니다. 이미 있으면 그 자리에서 갱신하고, 같으면 커밋하지 않습니다. README가 없으면 만듭니다.
- 폴더 선택 단계의 "연결하면 README에 CodeArchive 배지 추가" 체크박스(기본 켜짐)로 끌 수 있습니다.
- 보호된 브랜치, 마크다운이 아니거나 여러 개인 README, 64KB가 넘는 README는 건드리지 않고 이유를 알려 줍니다. README에 쓰지 못해도 연결은 유지됩니다.

## 서버 (확장보다 먼저 배포)
- 쉬는 DB 연결이 Neon 컴퓨트를 계속 깨우던 문제를 고쳤습니다(#503, 2026-11-04 배포).
- README 배지 API와, 기본으로 꺼진 AI 코드 리뷰 준비(#507, DB 테이블 3개 추가)를 2026-11-10에 배포했습니다. AI 코드 리뷰는 운영자가 켜기 전까지 화면에 나타나지 않습니다.

## 업데이트 안내
- 이번 버전은 권한을 바꾸지 않습니다. `manifest.json`의 권한과 접속 허용 사이트는 1.0.8과 같습니다. 기존 로그인, GitHub 연결, 자동 커밋 설정은 그대로 유지됩니다.
- 확장 갱신 전에 열려 있던 문제 탭에는 새로고침 안내가 표시될 수 있습니다.

## 알려진 한계
- 팝업 높이는 실제 렌더링 코드를 헤드리스 Chrome으로 잰 값입니다. 다른 OS 글꼴에서는 조금 다를 수 있지만 600px까지 여유가 있습니다.
- 대시보드 일괄 커밋 카드의 갱신과 README 배지 추가는 자동 테스트로 확인했고, 스토어 설치본의 실제 사용 확인은 [#456](https://github.com/devkimhongjin/codeArchive/issues/456)에서 이어갑니다.

## 배포 절차
- `DEFAULT_PUBLISH`로 심사를 제출합니다. 심사를 통과하면 바로 공개됩니다.
