# CodeArchive Extension v1.0.7

## 변경 사항

### 정올 정답 저장 (#492)
- 정올 문제 목록이나 홈에서 사이트 안 링크로 문제에 들어가 정답을 제출하면, 정답을 잡고도 저장하지 못해 팝업 최근 문제에 나오지 않고 서버에도 등록되지 않던 문제를 고쳤습니다.
  - 정올은 화면을 옮길 때 페이지를 다시 읽지 않고 주소만 바꿉니다. 확장은 처음 열린 화면의 주소로 문제 화면인지 판단해, 목록에서 들어온 문제 화면을 문제 화면이 아니라고 보고 저장을 막았습니다. 주소창에 문제 주소를 직접 열었을 때는 저장돼 지금까지 드러나지 않았습니다.
  - 이제 탭의 현재 주소가 같은 사이트일 때는 그 주소로 판단합니다. 다른 사이트이거나 주소를 알 수 없으면 이전처럼 판단합니다.

### 프로그래머스 SQL 과거 풀이 (#493)
- 프로그래머스 과거 풀이 가져오기에서 SQL 문제도 후보로 보여 주고 서버에 등록합니다. SQL 문제는 사이트에 제출 이력이 없어, 문제 편집기에 저장된 마지막 코드를 가져오고 해결한 문제 목록의 해결 시각을 풀이 시각으로 씁니다.
- 정답을 낸 뒤 편집기 코드를 고쳤다면 정답 제출과 다를 수 있습니다. 후보 줄에 `편집기 저장 코드(정답 제출과 다를 수 있음)`로 표시하고 상태 문구에도 안내합니다.
- 빈 코드, 주석뿐인 코드, 초기 템플릿 그대로인 코드, 확장이 아직 구분하지 못하는 언어(Oracle)는 제외하고 그 건수를 알립니다.
- 개발용 빌드에서 SQL 27문제를 서버에 등록하고 GitHub 커밋까지 확인했습니다.

### SWEA 제출현황 문구 (#491)
- SWEA 제출현황 카드의 `동기화` 버튼은 서버 등록 여부와 관계없이 켜져 있습니다. 카드에는 사이트의 정답 제출이 몇 건인지 나오지 않아 미리 판단할 수 없기 때문입니다. 이 점이 드러나도록 상태 문구를 바꿨습니다.
  - `미등록` → `서버에 없음 · 동기화로 등록`
  - `N건 등록` → `서버 N건 등록 · 추가분은 동기화로 확인`
- 동작은 그대로입니다. 동기화를 누르면 사이트 정답 제출을 읽어 서버에 없는 것만 등록합니다. 정올·프로그래머스의 행 단위 문구는 바뀌지 않았습니다.

## 업데이트 안내

- 이번 버전은 권한을 바꾸지 않습니다. `manifest.json`의 권한과 접속 허용 사이트는 1.0.6과 같습니다. 기존 로그인, GitHub 연결, 자동 커밋 설정은 그대로 유지됩니다.
- 서버 변경이 없어 서버 배포가 필요 없습니다.
- 확장 갱신 전에 열려 있던 문제 탭에는 새로고침 안내가 표시될 수 있습니다. 작성 중인 코드를 확인한 뒤 새로고침해 주세요.

## 알려진 한계

- 실시간으로 이미 수집된 SQL 풀이가 과거 풀이 후보에서 빠지는지는 아직 확인하지 않았습니다. 목록의 해결 시각이 첫 정답 제출보다 몇 초 늦게 찍혀, 다른 언어와 같은 기준(같은 문제·언어, 2분 이내)으로 맞춰 봅니다.
- Oracle로 푼 SQL 문제는 가져오지 않습니다. 확장과 서버의 언어 구분을 함께 바꿔야 합니다.
- 정올 사이트 안 이동 뒤 정답 저장(#492)과 SWEA 문구(#491)는 자동 테스트로 확인했고, 스토어 설치본 확인은 [#456](https://github.com/devkimhongjin/codeArchive/issues/456)에서 이어갑니다.
- 1.0.6의 한계가 그대로 남아 있습니다. 이미 서버에 두 번 등록된 SWEA 풀이는 정리되지 않고, 정올은 후보 목록에 제출 시각이 없어 실시간 수집분과 맞춰 볼 수 없습니다.

## 배포 절차

- `STAGED_PUBLISH`로 심사를 제출합니다. 심사를 통과해도 자동 공개되지 않고, Developer Dashboard에서 게시해야 공개됩니다. 심사 완료 후 30일 안에 게시해야 합니다.
- 2026-10-28 상태 조회 기준 스토어에는 1.0.6이 공개돼 있고 심사 중이거나 대기 중인 제출은 없습니다.
- 심사 제출, 실제 스토어 공개, 설치본 업데이트 확인은 서로 구분해서 기록합니다.
