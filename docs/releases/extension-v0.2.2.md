# CodeArchive Extension v0.2.2

## 변경사항

- 과거 풀이 수집을 확장 프로그램에서 실행하고 로그인 없이 로컬에 저장하도록 정리했습니다.
- 과거 수집과 서버 동기화를 분리하고, 대시보드에서 수동 동기화·GitHub 커밋을 진행할 수 있도록 했습니다.
- 과거 수집 화면의 플랫폼·제출 선택, 진행 상태, 개별 제출 실패 처리 및 목록 탐색을 개선했습니다.
- 확장 프로그램이 새 GitHub 릴리스를 확인하고 다운로드 링크를 안내합니다.

## 업데이트 안내

ZIP 내용을 기존 설치 폴더에 덮어쓴 뒤 Chrome 확장 관리에서 새로고침하세요. 로컬 풀이를 유지하려면 확장을 삭제하지 마세요. 과거 수집 시 수집 화면과 원본 사이트 창을 함께 열어 두세요.
