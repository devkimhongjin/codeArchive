# CodeArchive Extension v0.2.4

## 변경사항

- 정올의 제목 없는 정답 결과창에서 신규 정답 풀이가 저장되지 않던 문제를 수정했습니다. `aria-label`로 표시되는 결과창도 인식합니다.
- 기존 제목이 있는 결과창도 계속 지원하며, 정답100점·결과창 연결·표시 상태를 확인합니다.
- 정올 수집 단계에 코드·계정 정보가 없는 진단 표시를 추가했습니다. 저장 성공 응답을 받은 제출은 중복 저장하지 않습니다.
- 앞으로 새 릴리스에 버전별 변경사항과 업데이트 안내를 자동으로 포함합니다.

## 업데이트 안내

ZIP 내용을 기존 설치 폴더에 덮어쓴 뒤 Chrome 확장 관리에서 CodeArchive를 새로고침하세요. 로컬 풀이를 유지하려면 확장을 삭제하지 마세요.

**이미 열린 정올 문제 탭도 코드를 확인한 뒤 새로고침해야 수정된 수집기가 적용됩니다.** 새 정답 제출 후 팝업의 최근 저장 목록에서 확인해 주세요.

## 검증 범위

정올 실제 결과창 DOM 확인 및 회귀 테스트·Chrome 합성 화면 검증을 수행했습니다. 사용자 환경에서 업데이트 후 실제 신규 제출의 로컬 저장 확인은 별도로 진행합니다. Netlify 대시보드는 이번 릴리스에서 배포하지 않습니다.
