# CodeArchive Extension v0.2.1

## 변경사항

- GitHub 저장소 관리 화면과 연결 저장소 탐색 기능을 추가했습니다.
- 복사·다운로드·GitHub 커밋에 넣는 주석 항목을 설정에서 선택할 수 있도록 했습니다.
- 확장 팝업의 최근 풀이 복사·다운로드에도 주석 설정을 반영했습니다.

## 업데이트 안내

압축 해제 설치는 ZIP 내용을 기존 설치 폴더에 덮어쓴 뒤 Chrome 확장 관리에서 새로고침하세요. 로컬 풀이를 유지하려면 확장을 삭제하지 마세요. 이미 열린 문제 탭은 코드를 확인한 뒤 새로고침해야 새 수집 스크립트가 적용됩니다.
