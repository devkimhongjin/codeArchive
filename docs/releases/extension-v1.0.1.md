# CodeArchive Extension v1.0.1

## 변경 사항

- 과거 풀이 관리의 후보 중복 제외 기준을 로그인한 계정의 서버 제출 기록으로 통일했습니다. 후보 선택 후 원본 확인과 서버 등록을 이어서 진행합니다.
- 수집 후 별도 일괄 동기화 단계를 제거하고, 서버 등록 완료 후 GitHub 커밋 버튼을 화면 상단에 표시합니다.
- 새 정답 풀이도 서버 등록 응답을 받은 경우에만 저장 완료로 처리합니다. 풀이 코드는 확장 로컬 저장소에 새로 보관하지 않습니다.
- GitHub 관리에 전체 서버 풀이의 미커밋 제출을 선택해 일괄 커밋하는 기능을 추가했습니다. 완료·진행 중·결과 확인 필요 상태는 재요청 대상으로 자동 선택하지 않습니다.
- 긴 일괄 커밋은 확장 백그라운드에서 이어집니다. 관리 화면 탭을 이동하거나 닫은 뒤 다시 열면 접수·완료·실패 상태를 확인할 수 있습니다.
- 팝업 최근 문제의 코드 복사·다운로드 버튼을 복원했습니다. 버튼 클릭 시 본인 계정의 서버에서 최근 문제 원본을 가져옵니다.
- GitHub 로그인 시작 시 빈 탭 대신 진행 안내를 표시합니다. 로그인 준비 요청에 응답 제한 시간을 추가했습니다.

## 사용 조건과 업데이트 안내

풀이 등록·조회에는 CodeArchive 로그인과 서버 연결이 필요합니다. 통신 실패를 저장 완료로 표시하지 않으며, 과거 수집을 다시 실행하면 서버 기록에서 중복을 확인합니다. 과거 수집 시 사이트의 제출 화면을 유지해 주세요. Chrome 종료 중에는 확장의 추가 커밋 접수가 진행되지 않으며 이미 서버에 접수된 작업은 서버에서 처리합니다.

인증·설정과 원본 코드가 없는 작업 진행 정보만 Chrome에 유지합니다. 이전 버전의 로컬 풀이를 임의로 삭제하지 않으며, 개발자 모드 확장과 스토어 확장의 데이터가 자동 이전된다고 가정하지 않습니다.

이 버전은 구현·검증용 후보입니다. API·worker 적용과 실제 스토어 계정 검증 후 master 기준 릴리스 및 웹스토어 심사를 진행해야 합니다. 현재 게시 버전이 즉시 변경되었다는 뜻은 아닙니다.
