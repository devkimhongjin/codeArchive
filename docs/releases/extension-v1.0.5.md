# CodeArchive Extension v1.0.5

## 변경 사항

### 정올 수집 복구 (#472)
정올 사이트의 화면 변경으로 확장 업데이트 없이 수집이 실패하던 문제를 고쳤습니다.

- 실행 시간이 1초를 넘는 정답 제출을 수집하지 못하던 문제를 고쳤습니다. 결과창이 `1,511ms`처럼 쉼표를 넣어 표시하는 형식을 인식합니다.
- 정답 결과창의 메모리를 올바른 단위로 저장합니다. 결과창은 KiB 값에 `MB`를 붙여 표시하므로(예: 목록 `33.0MB`, 결과창 `33,796MB`) 이를 보정합니다. (#326)
- 제출할 때 뜨던 `CodeArchive · 자동 동기화 확인 필요` 팝업을 없앴습니다. 이 팝업이 뜨면 해당 제출이 저장되지 않았는데, 이제 정답 제출은 로그인된 계정으로 기기에 먼저 저장하고 서버 연결이 준비되면 자동으로 전송합니다. 자동 동기화를 꺼 둔 경우에만 저장하지 않습니다.
- 팝업에서 GitHub 자동 커밋을 바꾼 직후 서버 연결 정보 갱신이 실패하면, 그 뒤의 제출이 계속 막히고 브라우저를 다시 시작해야 복구되던 문제를 고쳤습니다. 이제 제출은 그대로 저장하고, 전송할 때 로그인 상태로 연결 정보를 다시 받아 올립니다.

### 정올 과거 풀이 수집 (#472)
- 제출 상세의 제출 시각이 마우스를 올려야 보이도록 바뀐 정올 화면에 맞춰, 시각을 다시 읽습니다.
- 정올 창 크기에 따라 후보 찾기가 실패하던 문제를 고쳤습니다. 창이 좁아 번호·시간·메모리·코드 길이 칸이 접혀도 같은 후보를 찾습니다.
- 정올 제출현황을 미리 열어 둘 필요가 없습니다. `후보 찾기`를 누르면 확장이 내 제출현황을 백그라운드 탭에서 열고, 가져오기가 끝나거나 과거 풀이 화면을 닫으면 그 탭을 닫습니다. 10분 동안 사용하지 않아도 닫습니다.

### 개선
- 코드 보기 화면은 표시하는 언어의 하이라이트 데이터만 불러옵니다. 예를 들어 Java 풀이를 열 때 받는 양이 약 2.2MB에서 27kB로 줄었습니다. (#474)

### 권한 축소 (#462)
- 더 이상 사용하지 않는 Netlify Dashboard(`codearchive-dashboard-beta.netlify.app`) 접속 권한과 외부 웹 페이지 연결을 제거했습니다. 이제 어떤 웹 페이지도 확장에 메시지를 보낼 수 없습니다.
- 기존 설치본에 저장된 Netlify 연결 주소는 서버 주소로 자동 이전합니다. 다시 로그인할 필요는 없습니다.

## 업데이트 안내

- 이번 버전은 권한을 줄이기만 하고 새 권한을 요청하지 않습니다. 기존 로그인, GitHub 연결, 자동 커밋 설정은 그대로 유지됩니다.
- 서버 API는 바뀌지 않아 백엔드 배포가 필요 없습니다.
- 확장 갱신 전에 열려 있던 문제 탭에는 새로고침 안내가 표시될 수 있습니다. 작성 중인 코드를 확인한 뒤 새로고침해 주세요.

## 배포 절차

- 이번 버전부터 `STAGED_PUBLISH`로 심사를 제출합니다(#471). 심사를 통과해도 자동 공개되지 않고, Developer Dashboard에서 게시해야 공개됩니다. 심사 완료 후 30일 안에 게시해야 합니다.
- 1.0.4가 심사 중이면 게시 스크립트는 다른 심사본이 있다는 이유로 1.0.5 제출을 거부합니다. 1.0.4 심사를 마치고 공개하거나 심사를 취소한 뒤 제출합니다.
- 심사 제출, 실제 스토어 공개, 설치본 업데이트 확인은 서로 구분해서 기록합니다.
