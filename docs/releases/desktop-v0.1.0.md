# CodeArchive Desktop v0.1.0

- 로그인 서버가 요청을 거부하거나 요청 한도를 넘으면 원인별 안내를 표시하고 다시 시도할 수 있도록 했습니다.
- 설치 완료 화면에 바탕 화면·시작 메뉴 바로가기 체크박스를 추가했습니다.
- 앱 메뉴바를 제거하고 확장 팝업은 미연결 시 PC 앱 연결만 표시하도록 정리했습니다.
- 확장 업데이트 항목·별도 조회를 제거하고 앱에 포함된 확장으로 갱신합니다.
- GitHub/Google 인증을 웹브라우저에서 진행하고 일회용 승인으로 PC 앱 독립 세션을 생성합니다. 웹 로그인 API 적용·활성화가 필요합니다.
- 설치 파일에 Chrome 확장을 포함하고 첫 실행에 설치 폴더·Chrome 등록·앱 연결 안내를 제공합니다.
- 사용자 제공 이미지로 PC 앱과 Chrome 확장 아이콘을 통일했습니다.
- 기존 대시보드 화면을 포함한 Windows PC 앱을 추가했습니다.
- 6자리 일회성 연결 코드로 Chrome 확장과 연결합니다. 기존 로컬 풀이를 이동하거나 삭제하지 않습니다.
- 앱 로그인 세션으로 서버 동기화와 GitHub 기능을 사용할 수 있습니다.
- 서명된 GitHub 릴리스 확인과 업데이트 다운로드·적용을 지원합니다.
- Windows 로그인 시 트레이로 시작하는 옵션을 제공합니다. 기본값은 꺼짐입니다.
- 창을 닫으면 트레이에서 실행되며, 트레이 메뉴에서 종료할 수 있습니다.

확장 v0.3.0 이상이 필요합니다. Windows 보안 경고용 Authenticode 서명과 앱 자체 업데이트 검증 서명은 별개입니다.
