# CodeArchive Desktop v0.1.0

- 기존 대시보드 화면을 포함한 Windows PC 앱을 추가했습니다.
- 6자리 일회성 연결 코드로 Chrome 확장과 연결합니다. 기존 로컬 풀이를 이동하거나 삭제하지 않습니다.
- 앱 로그인 세션으로 서버 동기화와 GitHub 기능을 사용할 수 있습니다.
- 서명된 GitHub 릴리스 확인과 업데이트 다운로드·적용을 지원합니다.
- Windows 로그인 시 트레이로 시작하는 옵션을 제공합니다. 기본값은 꺼짐입니다.
- 창을 닫으면 트레이에서 실행되며, 트레이 메뉴에서 종료할 수 있습니다.

확장 v0.3.0 이상이 필요합니다. Windows 보안 경고용 Authenticode 서명과 앱 자체 업데이트 검증 서명은 별개입니다.
