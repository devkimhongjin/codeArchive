# CodeArchive Desktop v0.1.2

## 변경사항

- 모든 탭에서 PC 앱 현재 버전을 확인할 수 있습니다. 새 버전을 감지하면 업데이트 팝업을 표시합니다.
- 기본 꺼짐인 자동 업데이트 설정을 추가했습니다. 켜면 앱이 트레이에 있고 진행 중인 작업과 입력한 내용이 없을 때 자동으로 다운로드·적용합니다.
- 설정의 PC 앱 업데이트 영역에 현재 버전·업데이트 버전·상태와 확인·다운로드·적용 버튼을 모았습니다.
- 확장의 대시보드 열기는 웹페이지 대신 PC 앱을 실행합니다. 연결 전에도 PC 앱 열기 링크를 제공합니다.
- CodeArchive 이름 앞에 있던 B 아이콘을 헤더와 푸터에서 제거했습니다.
- GitHub 인증 화면으로 바로 이동하고 로그인 완료 후 앱으로 복귀합니다. 웹브라우저를 종료해도 앱의 독립 로그인 세션을 유지합니다.

## 포함 기능

Windows 대시보드, Chrome 확장 v0.3.1 포함과 첫 실행 등록·연결 안내, 앱·확장 공통 아이콘, 선택형 Windows 자동 시작, 트레이 실행, 설치 완료 화면의 바탕 화면·시작 메뉴 바로가기 선택을 포함합니다.

기존 PC 앱 v0.1.1에서는 설정 → PC 앱 설정 → 업데이트 확인 후 다운로드·적용을 실행할 수 있습니다. 앱 업데이트는 포함된 확장 파일도 갱신합니다. Chrome 확장 관리에서 확장을 새로고침해 주세요. 로그인과 확장 연결 설정·로컬 풀이는 유지됩니다.

릴리스는 master 소스에서만 발행하고 앱은 고정 공개키 서명·SHA256·릴리스 출처를 확인한 설치 파일만 적용합니다. Windows Authenticode 서명과 앱 업데이트 무결성 서명은 별개입니다.
