# CodeArchive Extension v0.3.0

## 변경사항

- Windows PC 앱과 연결하는 기능을 추가했습니다. 앱 설정에서 발급한 6자리 연결 코드를 확장 팝업에서 입력합니다.
- PC 앱에서도 기존 로컬 풀이 조회, 과거 풀이 관리, 서버 동기화 및 GitHub 작업을 사용할 수 있습니다. 서버 업로드 성공 후에만 로컬 동기화 완료 표시를 적용합니다.
- 웹 대시보드 연결과 기존 로컬 저장 데이터는 유지됩니다. PC 앱 연결을 해제해도 로컬 풀이를 삭제하지 않습니다.

## 업데이트 안내

기존 설치 폴더에 파일을 교체하고 Chrome 확장 관리에서 새로고침하세요. 이미 열린 문제 탭도 코드를 확인한 뒤 새로고침해 주세요. 로컬 풀이를 유지하려면 확장을 삭제하지 마세요.

PC 앱은 별도 설치 파일로 배포됩니다. 기존 사용자는 PC 앱을 설치하지 않고 웹 대시보드와 확장을 계속 사용할 수 있습니다.
