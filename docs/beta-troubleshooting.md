# CodeArchive 문제 해결·오류 제보

먼저 자동 동기화를 끄고 로컬 기록을 보존합니다. **재설치·브라우저 데이터 삭제·보호 기능 해제는 기본 해결책이 아닙니다.**

| 증상 | 먼저 확인할 것 | 다음 행동 |
| --- | --- | --- |
| 서버를 준비하고 있어요 | 경과 시간; 무료 서버 기동이나 일시적인 네트워크 지연 가능성 | 최대 3분까지 상태 조회만 진행; **대기 취소** 가능. 기다리는 동안 Extension 로컬 보관함 사용 가능 |
| 서버 연결을 확인해 주세요 / 대기를 취소했어요 | 화면의 네트워크·서버·응답 안내와 발생 시각 | **다시 확인**으로 새 대기 시작; 반복되면 운영자에게 제보. 상태 조회 실패는 로그아웃 판정이 아님 |
| manifest 파일을 찾을 수 없음 | 압축 해제한 `extension` 폴더 안의 `manifest.json` | ZIP/상위 폴더가 아닌 `extension`을 선택 |
| Extension을 찾을 수 없음 / 연결 오류 | 같은 Chrome 프로필, Extension 활성화, 정확한 ID, 공식 Dashboard 주소 | Extension 갱신 후 Dashboard 새로고침 → **다시 확인** |
| SWEA 정답이 로컬에 없음 | 설치/갱신 후 SWEA 탭 새로고침 여부, 지원 풀이 화면, 실제 정답 여부 | 코드를 별도 파일에 저장하고 발생 시각·화면 종류만 제보; 원인 확인 전 무조건 재제출하지 않음 |
| 로그인 화면이 안 열리거나 로그인 상태 오류 | Dashboard에서 **GitHub로 로그인**했는지, 서버 초기 응답 지연 여부 | 잠시 기다린 후 **다시 시도**; OAuth callback 주소 전체를 공유하지 않음 |
| 로그인 후 다시 로그아웃처럼 보임 | 같은 Chrome 프로필인지, 사이트별 쿠키/조직 정책 차단 여부 | 정책을 임의로 우회하거나 보호 기능을 전역 해제하지 말고 운영자에게 상황 전달 |
| 로컬에는 있는데 Dashboard가 비어 있음 | 로그인 계정, 자동 동기화 동의, Extension 연결, pending 수 | 전송에 동의한 기록만 있는지 확인 후 동기화; 이후 **목록 새로고침** |
| pending 수가 줄지 않음 / 일부 실패 | 서버가 깨어나는 중인지, 부분 전송 상태인지 | 자동 재시도 후 화면이 안내하는 재시도 사용; 기록을 삭제하거나 다른 계정으로 반복 전송하지 않음 |
| 자동 동기화를 켰는데 새 풀이가 안 보임 | Dashboard 탭이 열려 있는지, 연결이 유지되는지 | 탭을 열고 재연결, 목록 새로고침; 닫힌 동안에는 로컬에만 쌓임 |
| 서버에서 지운 기록이 다시 나타남 | 삭제 당시 해당 로컬 원본이 pending이었는지 | 재전송 가능성을 운영자와 확인; 서버 삭제가 로컬 삭제인 것으로 간주하지 않음 |
| AI가 느리거나 오류/한도 안내 | `fake` 표기와 현재 요청 상태 | 결과 새로고침으로 완료 여부부터 확인; 생성 버튼 연속 클릭 금지 |
| 업데이트 후 로컬 건수가 다름 | 같은 프로필·ID·로드 폴더인지 | 자동 동기화를 끄고 중단; 제거/저장소 초기화 없이 운영자에게 문의 |

공식 Dashboard: [codearchive-dashboard-beta.onrender.com](https://codearchive-dashboard-beta.onrender.com)

무료 서버는 처음 요청할 때 응답이 늦을 수 있습니다. 시간 초과는 데이터가 삭제됐다는 뜻이 아닙니다. 특히 AI 요청은 브라우저에 오류가 표시돼도 서버에서 계속 처리 중일 수 있으므로 기존 결과를 먼저 확인합니다.

서버 준비 화면은 Dashboard 시작 시에만 동작합니다. 열린 Dashboard를 오래 방치한 뒤 발생한 오류까지 자동으로 복구하지는 않습니다. 편집 중인 내용은 별도로 보존하고, 각 기능의 재시도/결과 확인 안내를 따르세요. 새 준비 화면은 로그인·동기화·게시·AI 생성 요청을 자동 반복하지 않습니다.

## 안전한 오류 제보

초대받은 연락 채널을 우선 사용하세요. GitHub를 사용할 수 있으면 [이슈 작성](https://github.com/devkimhongjin/codeArchive/issues/new)도 가능합니다. 접근 권한이 없다면 운영자에게 전달합니다.

아래 내용을 복사해 필요한 부분만 채웁니다.

```text
[CodeArchive 베타 오류]
발생 시각 / 시간대:
운영체제 / Chrome 버전:
받은 패키지 파일명 / 소스 커밋 / SHA-256:
설치/업데이트 여부:
발생 단계: 설치 / 로컬 수집 / 로그인 / 연결 / 동기화 / 관리 / AI
재현 순서:
기대한 결과:
실제 화면 메시지:
로컬 건수 / pending 수 (확인 가능한 경우):
민감정보를 가린 화면 (선택):
```

**첨부하지 않을 것:** 전체 코드·회사/학교 비공개 문제, 이메일/실명/프로필 사진, 토큰·쿠키·비밀번호·API 키, OAuth URL의 state/code, 원본 네트워크 로그/HAR. 화면을 공유할 때 코드 상세와 주소 표시줄도 확인하세요. 정상 로그 수집을 위해 인증정보나 전체 코드를 요구하지 않습니다.

다른 계정의 풀이가 보이거나 의도하지 않은 코드 전송이 의심되면 즉시 자동 동기화를 끄고 로그아웃한 뒤 운영자에게 비공개로 알리세요. 다른 사람 데이터를 확인·복사·추가 조회하지 않습니다.
