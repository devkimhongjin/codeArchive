# 비공개 문의·오류 제보

대시보드의 **문의·오류 제보**는 로그인한 사용자의 비공개 지원 채널입니다. `BUG`, `QUESTION`, `DATA_REQUEST` 분류와 제목, 사용자가 입력한 메시지만 보냅니다. 첨부 파일, 브라우저 로그, 소스 코드, 쿠키, 자격 증명을 자동으로 수집하지 않습니다.

## API와 접근 권한

- 모든 경로는 `/api/support`이며 GitHub 로그인 세션, CSRF 보호, `X-CodeArchive-Github-Id` 계정 일치 검사를 요구합니다. 이 헤더는 대시보드가 렌더링한 계정을 확인하는 주장일 뿐 인증 수단이 아닙니다.
- 사용자는 자신의 문의 목록·상세·메시지만 볼 수 있고, 메시지를 보내면 종료된 문의도 다시 열립니다. 본인 문의는 종료하거나 명시적 확인 뒤 삭제할 수 있습니다.
- 관리자 권한은 서버가 확인한 GitHub 고유 ID `301944193`(devkimhongjin)의 로그인과 저장된 동일 계정에만 부여됩니다. 사용자명, 요청 헤더, 클라이언트 상태는 권한을 만들지 않습니다.
- 관리자만 `/admin/tickets` 목록·상세·답변·상태 변경을 사용할 수 있습니다. 일반 사용자의 관리자 요청은 403이고, 다른 사용자의 문의는 404입니다.

`GET /access`, `GET/POST /tickets`, `GET /tickets/{id}`, `POST /tickets/{id}/messages`, `POST /tickets/{id}/close`, `DELETE /tickets/{id}`, 그리고 관리자용 `GET /admin/tickets`, `GET /admin/tickets/{id}`, `POST /admin/tickets/{id}/messages`, `PUT /admin/tickets/{id}/status`를 제공합니다. 목록은 페이지당 20건이며 응답은 `Cache-Control: no-store`입니다.

## 보관과 요청 처리

종료 후 90일이 지난 문의는 다음 문의 기능 접근 시 자동 삭제됩니다. 정기 실행이나 정확한 삭제 시각은 약속하지 않습니다. 사용자가 직접 삭제하면 해당 문의의 메시지도 외래 키 연결에 따라 함께 삭제됩니다. 열린 문의와 사용자가 후속 메시지로 다시 연 문의는 이 정리에 포함하지 않습니다.

`DATA_REQUEST`는 서버 데이터·계정 접근·정정·삭제를 요청하는 비공개 채널입니다. 요청은 관리자가 검토하며, 이 기능은 자동 계정 삭제를 구현하지 않습니다. 백업의 보관 기간이나 삭제 시점은 이 문서에서 단정하지 않습니다. 민감하지 않은 공개 버그 보고만 GitHub Issues를 사용하고, 계정 정보·비공개 코드·자격 증명은 올리지 마세요.
