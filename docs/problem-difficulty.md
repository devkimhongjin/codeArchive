# 플랫폼별 난이도 (#337)

공식 페이지의 문제 번호와 난이도가 한 항목에 연결된 경우만 저장한다. SWEA D1–D8, 프로그래머스 Lv. 0–5는 서로 다른 척도로 표시·필터링하며 교차 순위를 만들지 않는다. 정올은 신뢰할 공식 티어 원천이 없어 미확인으로 남긴다. BOJ 번호나 solved.ac 티어를 대입하지 않는다.

- SWEA: 본인 제출 원본 검증 후 문제 제목의 번호와 유일한 난이도 배지를 확인한다.
- 프로그래머스: 공식 해결 목록의 문제 링크와 같은 행 Lv 셀을 확인한다. 문제 상세에 없으면 임의 추정하지 않는다.
- 기존 제출은 누락 풀이 대조 → 기존 제출 정보 확인에서 원본을 다시 검증한 뒤 비어 있는 정보만 보강한다. 일괄 동기화로 서버에 반영한다.
- V27은 nullable 열만 추가한다. 운영 풀이의 난이도를 추측하거나 일괄 변경하지 않는다.

검증: 프로그래머스 실제 Chrome 목록의 Lv. 3/Lv. 2 구조 확인; SWEA 번호/배지 연결 및 공식 URL 검증은 DOM fixture 테스트. SWEA 로그인 후 실제 원본 보강 및 설치된 확장 화면 검증은 별도 인수 조건이다.
