# CodeArchive v0.3.3 웹스토어 입력 초안

관련 #400/#422. 로컬 정적 분석을 제거한 제출 후보입니다. 업로드·심사·게시 완료가 아닙니다.

## 스토어 목록

- 이름: CodeArchive
- 기본 언어: 한국어
- 단일 목적: 본인의 알고리즘 정답 풀이를 기록·조회하고 선택한 GitHub 저장소로 관리합니다.
- 요약: SWEA·프로그래머스·정올 정답 풀이를 기록하고, 확장 대시보드에서 조회·동기화·GitHub 커밋을 관리합니다. 이 한국어 문구는 권장안이며 manifest.description 반영 여부를 따로 확인합니다.

### 상세 설명

SWEA, 프로그래머스, 정올에서 제출한 본인 정답 풀이를 CodeArchive로 관리하세요.

확장 대시보드에서 문제와 제출을 조회하고 코드를 복사·다운로드하거나 65개 코드 테마를 선택할 수 있습니다. 로그인한 계정의 신규 정답은 자동 동기화하며, GitHub App 저장소 연결 후 자동 커밋을 ON/OFF할 수 있습니다.

과거 풀이 관리에서는 본인 정답·원본 코드·제출 시각을 확인한 뒤 선택한 기록을 수집합니다. 완료 후 저장에 성공한 선택 제출만 일괄 동기화하고, 저장소·브랜치·파일 경로를 확인해 GitHub 커밋을 요청할 수 있습니다.

커뮤니티 풀이 공개 설정과 중복 제출 공개 방식을 직접 정하고, 공개 풀이를 정렬하거나 좋아요·댓글을 남길 수 있습니다. 기본 풀이 공개 설정은 공개이며 설정에서 비공개로 바꿀 수 있습니다.

문의·오류 제보는 GitHub 로그인 후 비공개로 접수합니다. 접수됨·확인중·답변완료 상태와 관리자 답변을 확인하며, 채팅식 후속 메시지나 임의 종료·삭제는 제공하지 않습니다. 이 정책은 최신 API/V29가 실제 운영 서버에 적용됐는지 확인한 후 안내합니다.

별도 PC 앱은 필요하지 않습니다. Chrome을 완전히 종료하면 확장 작업은 실행되지 않습니다. 과거 수집 중에는 수집 화면과 원본 사이트 창을 모두 열어 두세요. 사이트가 제공하지 않는 실행시간·메모리는 만들지 않습니다.

## 개인정보·권한·이미지

[권한 설명](../extension-webstore.md#권한-설명-초안)과 [데이터 처리 안내](../extension-privacy.md)를 기준으로 실제 처리 내용을 입력합니다. 이 변경은 브라우저 권한이나 데이터 수집 범위를 넓히지 않습니다. 분석 기능과 분석 결과 화면은 제공하지 않습니다.

최종 ZIP의 실제 UI로 새 캡처를 촬영합니다. 이전 v0.3.2 분석 캡처는 사용하지 않습니다. 데모 데이터를 사용한 캡처는 실제 사용자 동기화·계정 수용 증거로 표시하지 않습니다. 기존 아이콘과 작은 홍보 타일은 기능을 특정하지 않으므로 재사용할 수 있습니다.

master 공개 개인정보 URL의 최신 변경 반영, 실제 스토어 ID·로그인 복귀·CORS, 서버 문의 정책, 기존 로컬 데이터 이전과 최종 제출은 별도 확인 항목입니다. 이 작업만으로 production 배포나 master 병합을 실행하지 않습니다.
