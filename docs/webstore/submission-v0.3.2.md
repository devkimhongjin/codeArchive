# CodeArchive v0.3.2 웹스토어 입력 초안

관련 #400/#415/#417. 상태는 패키지/제출 자료 준비이며 업로드·심사·게시 완료가 아닙니다.

## 스토어 목록

- 이름: CodeArchive
- 기본 언어: 한국어
- 요약: SWEA·프로그래머스·정올 정답 풀이를 기록하고, 확장 대시보드에서 조회·동기화·GitHub 커밋을 관리합니다.
- 단일 목적: 본인의 알고리즘 정답 풀이를 기록·조회하고 선택한 GitHub 저장소로 관리합니다.

### 상세 설명

SWEA, 프로그래머스, 정올에서 제출한 본인 정답 풀이를 CodeArchive로 관리하세요.

확장 대시보드에서 문제와 제출을 조회하고 코드를 복사·다운로드하거나 65개 코드 테마를 선택할 수 있습니다. 로그인한 계정의 신규 정답은 자동 동기화하며, GitHub App 저장소 연결 후 자동 커밋을 ON/OFF할 수 있습니다.

과거 풀이 관리에서는 본인 정답·원본 코드·제출 시각을 확인한 뒤 선택한 기록을 수집합니다. 완료 후 저장에 성공한 선택 제출만 일괄 동기화하고, 저장소·브랜치·파일 경로를 확인해 GitHub 커밋을 요청할 수 있습니다.

커뮤니티 풀이 공개 설정과 중복 제출 공개 방식을 직접 정하고, 공개 풀이를 정렬하거나 좋아요·댓글을 남길 수 있습니다. 기본 풀이 공개 설정은 공개이며 설정에서 비공개로 바꿀 수 있습니다. 로컬 정적 분석은 코드를 실행하거나 분석을 위해 외부 AI로 전송하지 않습니다.

문의·오류 제보는 GitHub 로그인 후 비공개로 접수합니다. 접수됨·확인중·답변완료 상태와 관리자 답변을 확인하며, 채팅식 후속 메시지나 임의 종료·삭제는 제공하지 않습니다.

별도 PC 앱은 필요하지 않습니다. Chrome을 완전히 종료하면 확장 작업은 실행되지 않습니다. 과거 수집 중에는 수집 화면과 원본 사이트 창을 모두 열어 두세요. 사이트가 제공하지 않는 실행시간·메모리는 만들지 않습니다.

## 개인정보·권한 입력

[권한별 사용 이유](../extension-webstore.md#권한-설명-초안)와 [개인정보 안내](../extension-privacy.md)를 기준으로 입력합니다. 정책 URL은 `https://github.com/devkimhongjin/codeArchive/blob/master/docs/extension-privacy.md`입니다.

- 사용자 제공 코드·댓글·문의 내용, 문제·언어·제출 시각·선택 성능 정보, 계정 식별 정보·닉네임·인증 연결 정보를 다룹니다.
- 전체 웹 탐색 이력, 다른 사이트 문서, 비밀번호 입력란을 수집하지 않습니다. 확장이 쿠키 값을 읽지 않습니다.
- React·Shiki·파서·worker는 패키지 내부에 포함하며 원격 실행 코드를 사용하지 않습니다.
- 문의 자동 삭제와 임의 삭제 UI를 제거했습니다. 접근·정정·삭제 요청은 인증된 비공개 문의를 통해 관리자가 본인 확인 후 검토합니다. 백업 보관/삭제 시점은 미확인입니다.
- 이 개인정보/문의 정책은 API/V29 적용 후 운영 화면과 함께 확인해야 합니다. 코드 병합만으로 현재 배포 서버 정책이 바뀌었다고 표시하지 않습니다.

## 이미지와 검수 자료

- 128×128 PNG 아이콘: 패키지의 `icons/icon-128.png` 사용.
- 작은 홍보 이미지 440×280 및 실제 화면 캡처 최소 1장(1280×800 또는 640×400) 필요. 이전 버전 캡처는 실제 최종 UI와 일치하는 경우에만 재사용합니다.
- 계정·인증 정보·비공개 원본 코드가 없는 검증 자료로 촬영합니다. 생성 목업을 실제 화면 캡처로 표시하지 않습니다.
- 심사용 사용 방법: 로컬 캡처는 로그인 없이 확인, 서버 문의는 GitHub 로그인 후 접수/상태/답변 확인. 운영 관리자 자격 증명을 제출 자료에 넣지 않습니다.

## 남은 확인

master SHA/버전/ZIP 해시 일치, 실제 Item ID·공개 키 및 API 허용 origin, 로컬 IndexedDB 이전 방안, 최종 ZIP 로그인 복귀·캡처·동기화·재시작 복구, 사용자/관리자 문의, 이미지·데이터 사용 고지·공개 개인정보 URL을 확인합니다. 스토어 ID는 개발용 ID `oohlcmihldmfninmdcmanddfmhoonmdl`로 단정하지 않습니다.

사용자는 실제 Chrome 수용 전 master 승격과 출시 준비를 요청했습니다. 미완료 수용을 통과로 바꾸지 않으며, 게시/심사 요청은 새 승인 전 실행하지 않습니다.

공식 참고: [게시 절차](https://developer.chrome.com/docs/webstore/publish), [개인정보 입력](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy), [이미지 규격](https://developer.chrome.com/docs/webstore/images).
