# CodeArchive v0.3.1 웹스토어 입력 초안

상태: 제출 준비. 실제 업로드·심사·게시 전 미완료 항목을 확인합니다. 운영 계정·코드·인증 정보를 테스트 자료에 넣지 않습니다.

## 스토어 목록

- 이름: CodeArchive
- 기본 언어: 한국어
- 요약: SWEA·프로그래머스·정올 정답 풀이를 기록하고, 확장 대시보드에서 조회·동기화·GitHub 커밋을 관리합니다.
- 단일 목적: 본인의 알고리즘 정답 풀이를 기록·조회하고 선택한 GitHub 저장소로 관리합니다.

### 상세 설명

SWEA, 프로그래머스, 정올에서 제출한 본인 정답 풀이를 CodeArchive로 관리하세요.

확장 대시보드에서 문제와 제출을 조회하고, 코드를 복사·다운로드하거나 65개 코드 테마를 선택할 수 있습니다. 로그인한 계정의 신규 정답은 자동 동기화하며, GitHub App 저장소 연결 후 자동 커밋을 ON/OFF할 수 있습니다.

과거 풀이 관리에서는 플랫폼과 같은 문제 제출 기준을 선택해 본인 정답·원본 코드·제출 시각을 확인합니다. 수집 완료 후 성공한 선택 제출만 일괄 동기화하고, 저장소·브랜치·파일 경로를 확인해 GitHub 커밋을 요청할 수 있습니다.

커뮤니티 공개 설정과 중복 제출 공개 방식을 직접 정하고, 공개 풀이를 정렬하거나 좋아요·댓글을 남길 수 있습니다. 기본 풀이 공개 설정은 공개이며 설정에서 비공개로 바꿀 수 있습니다. 로컬 정적 분석은 코드를 실행하거나 분석을 위해 외부 AI에 전송하지 않습니다.

별도 PC 앱은 필요하지 않습니다. Chrome을 완전히 종료하면 확장 작업은 실행되지 않습니다. 과거 수집 중에는 수집 화면과 원본 사이트 창을 모두 열어 두세요. 프로그래머스 제출 이력에서 제공하지 않는 실행시간·메모리는 수집하지 않습니다.

## 개인정보·권한 입력

[권한별 사용 이유](../extension-webstore.md#권한-설명-초안)와 [개인정보 안내 초안](../extension-privacy.md)을 기준으로 작성합니다. 공개 정책 URL 후보는 master의 개인정보 문서이나, 보관·삭제·비공개 문의 절차를 확정하기 전 최종 정책으로 등록하지 않습니다.

- 코드 원문·댓글 등 사용자 제공 콘텐츠와 문제·언어·제출 시각·성능 정보, 계정 식별 정보와 닉네임, 인증 연결 정보를 다룹니다.
- 전체 웹 탐색 이력이나 다른 사이트 문서, 비밀번호 입력란을 수집하지 않습니다. 브라우저 쿠키 값을 확장이 읽지 않습니다.
- 원격 실행 코드는 사용하지 않습니다. React·Shiki·파서·worker를 패키지에 포함합니다.
- 개인정보 카테고리와 이용 목적의 최종 체크는 실제 구현·운영 정책과 일치해야 합니다. 아직 확인하지 않은 보관 기간이나 삭제 기능을 약속하지 않습니다.

## 이미지 준비

Google 공식 [이미지 안내](https://developer.chrome.com/docs/webstore/images)에 따라 다음을 준비합니다.

- 아이콘: 패키지에 포함한 128×128 PNG, 밝고 어두운 배경에서 확인.
- 작은 홍보 이미지: 440×280, 실제 브랜드 이미지 사용.
- 실제 확장 화면 캡처: 최소 1개, 1280×800 또는 640×400. 전체 풀이·팝업·과거 관리·테마 미리보기 중 핵심 화면 사용.
- 운영 계정·문제 코드·인증 정보를 노출하지 않도록 검증용 자료 사용. 목업을 실제 화면 캡처로 표기하지 않습니다.

## 최종 확인

| 항목 | 상태 |
| --- | --- |
| develop 통합 → master 승격 | 이번 작업에서 PR·SHA·CI 근거 기록 |
| master 출처 ZIP·SHA256·파일 목록 | 이번 작업의 output 준비 폴더에 생성 |
| 웹스토어 계정/Item ID·공개 키 | 미확인, 로컬 ID를 실제 스토어 ID로 단정하지 않음 |
| 스토어 ID 로그인 반환/API CORS | 미검증, 실제 ID 발급 후 확인 |
| 최종 ZIP 자동 동기화·커밋·작업 복구 | 실브라우저 사용자 검증 필요 |
| 작은 홍보 이미지·실제 화면 캡처 | 준비 필요 |
| 보관 기간·삭제 요청·비공개 문의 절차 | 운영자 확정 필요 |
| 최종 정책 URL·데이터 고지 | 정책 확정 후 공개 접근 확인·등록 |
| 웹스토어 업로드/심사 요청 | 미실행 |

공식 참고: [게시 절차](https://developer.chrome.com/docs/webstore/publish), [개인정보 입력](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy), [최소 권한](https://developer.chrome.com/docs/webstore/program-policies/permissions).
