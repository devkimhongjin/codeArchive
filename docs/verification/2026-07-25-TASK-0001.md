## 발견 결함

### BUG-TASK-0001-01 — GitHub 경로 정규화 누락

- 심각도: High / 차단
- 관련 AC: AC-07
- 위치: `src/common/validators/index.ts`의 `parseSolutionSession`,
  `compareSolutionSessions`
- 재현: 같은 세션 후보의 경로를 `./solutions\A.java`와
  `solutions/A.java`로 비교한다.
- 기대: `\`→`/`, 선행 `./`·`/` 제거 후 weak candidate
- 실제: 문자열을 trim한 뒤 그대로 비교하여 `none`

### BUG-TASK-0001-02 — URL trailing slash 정규화 누락

- 심각도: Medium / 차단
- 관련 AC: AC-07
- 위치: `normalizeProblemUrl`
- 재현: `https://example.com/problem/1206/`와
  `https://example.com/problem/1206`을 정규화 후 비교한다.
- 기대: 동일한 strong key
- 실제: trailing slash가 유지되어 서로 다른 key

### BUG-TASK-0001-03 — 승인된 필수 테스트·실패 fixture 누락

- 심각도: High / 차단
- 관련 AC: AC-02~06, AC-09
- 재현: `tests/unit/data-contract.test.ts`와 `tests/fixtures`를 AC 자동 테스트
  목록과 대조한다.
- 기대: 각 명시 사례와 실패 fixture 존재
- 실제: Vitest는 10개 통과하지만 위 표의 필수 사례가 수집되지 않음

## 보안·fixture·잔여 위험

- 새 Chrome 권한, 외부 통신, dependency 변경은 발견되지 않았다.
- fixture는 합성 최소 코드와 공개 식별 예시만 포함하며 토큰·개인정보·문제 원문·비공개
  테스트 케이스는 발견되지 않았다.
- 실제 플랫폼 DOM 정확도는 TASK-0001 비범위다.
- 커버리지는 측정하지 않았으며 달성으로 기록할 수 없다.
