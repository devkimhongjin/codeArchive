# CodeArchive 데이터 처리 안내

이 문서는 현재 구현된 데이터 처리와 사용자 제어 수단을 설명합니다. 자동 계정 삭제나 확인하지 않은 백업 보관 기한은 약속하지 않습니다. master 승격 후 공개 정책 참조 URL은 `https://github.com/devkimhongjin/codeArchive/blob/master/docs/extension-privacy.md`이며, Chrome 웹스토어 개인정보 입력란 등록·공개 접근 확인은 별도 출시 확인 항목입니다.

## 처리하는 정보

- 본인 정답 풀이의 원본 코드, 플랫폼·문제 번호·제목·주소, 언어, 결과, 제출 식별자와 시각, 제공되는 실행시간·메모리·코드 길이.
- GitHub 로그인에서 제공된 계정 ID·닉네임·프로필 이름·이메일·아바타. GitHub에서 제공하지 않는 항목은 없을 수 있습니다.
- 테마·내보내기 설정, 연결된 GitHub 저장소·브랜치·경로, 자동 커밋 선택, 커뮤니티 공개 설정, 동기화·커밋 작업 상태.
- 공개 풀이에 대한 좋아요와 댓글.
- 계정 확인 및 동기화 요청을 인증하는 연결 정보. GitHub/OAuth 인증 정보는 서버에서 처리하며 브라우저의 로그인 쿠키 값은 확장이 읽지 않습니다.

사이트 결과와 제출 목록에서 필요한 정보를 확인합니다. 정답으로 확인되지 않은 코드나 다른 사용자의 제출은 본인 풀이로 수집하지 않습니다. 전체 방문 기록, 다른 사이트의 문서, 비밀번호 입력란을 수집하지 않습니다.

## 사용 목적과 저장

풀이 조회·검색·코드 표시, 중복 제출 확인, 수집 중단 후 복구, 서버 동기화, 선택한 GitHub 저장소에 기록, 사용자가 정한 커뮤니티 공개와 댓글·좋아요에 사용합니다.

개인정보와 코드 콘텐츠를 판매하거나 광고 목적으로 사용하거나 AI 학습에 사용하지 않습니다.

확장은 풀이 원본을 서버 등록 요청 중 메모리에서만 처리하고, 새 풀이 코드를 IndexedDB에 보관하지 않습니다. 로그인한 계정의 서버 기록을 중복 비교·풀이 목록·최근 문제의 기준으로 사용합니다. 과거 수집도 로그인 후 원본을 확인해 서버에 직접 등록합니다. 서버에서 등록을 확인하지 못한 경우 저장 완료로 표시하지 않으며, 다음 후보 찾기에서 서버 기록을 확인해 다시 시도할 수 있습니다.

확장의 인증 연결 정보, 설정과 코드가 없는 작업 진행 메타데이터(계정·대상 저장소·capture ID·처리 위치·상태)는 Chrome에 보관합니다. 기존 버전의 로컬 풀이를 임의로 삭제하거나 다른 확장 ID의 데이터가 자동 이전된다고 가정하지 않습니다. 일괄 GitHub 커밋은 관리 화면을 닫아도 확장 서비스 워커가 이어가며, Chrome 종료 중에는 추가 요청을 진행하지 않습니다. 이미 서버에 접수된 커밋은 서버 worker에서 처리됩니다. 최근 문제의 복사·다운로드는 유효한 계정 연결로 서버의 최근 세 문제 원본을 읽은 뒤 요청한 작업을 실행합니다.

GitHub 로그인과 서버 동기화에 CodeArchive API를 사용합니다. 연결된 GitHub 저장소에 대한 커밋은 자동 커밋 ON 또는 명시적인 수동 커밋 요청에 따라 처리합니다. 저장소의 공개·비공개 상태는 GitHub 설정에 따릅니다. CodeArchive에서 공개를 취소해도 이미 GitHub에 커밋한 코드는 자동 삭제하지 않습니다.

## 커뮤니티 공개

새 정답의 기본 공개 설정은 공개이며 설정에서 비공개를 선택할 수 있습니다. 공개한 코드, 닉네임과 풀이 성능 정보는 같은 플랫폼·문제의 풀이를 공개한 로그인 사용자에게 표시됩니다. 공개된 풀이에는 좋아요와 댓글을 남길 수 있습니다.

개별 공개를 취소할 수 있습니다. 중복 제출 공개 방식을 변경하면 기존 정답 풀이에도 즉시 적용되며, 전체 공개 또는 실행시간·메모리·코드 길이 기준의 한 제출 공개를 선택합니다. 상대방이 이미 복사한 코드나 GitHub 기록까지 회수하지는 않습니다.

## 정보 관리와 현재 제한

관리 화면에서 계정 로그아웃, GitHub 자동 커밋 ON/OFF, 풀이 공개 설정을 변경할 수 있습니다. 확장 삭제 또는 Chrome 프로필 데이터 삭제는 로컬 기록을 지울 수 있으며 서버 기록이나 GitHub 커밋을 자동 삭제하지 않습니다.

계정 및 서버 기록의 접근·정정·삭제 요청은 인증된 대시보드의 비공개 문의로 받습니다. 문의에는 사용자가 입력한 분류·제목·메시지, 작성자 계정 ID, 작성·수정 시각과 처리 상태만 보관하며 첨부 파일, 브라우저 로그, 코드, 쿠키, 자격 증명을 자동 수집하지 않습니다. 문의는 접수됨·확인중·답변완료 상태로 관리하며 채팅 형태의 후속 메시지, 임의 종료·삭제, 기간 경과에 따른 자동 삭제를 하지 않습니다. 문의 기록의 정정·삭제 요청은 관리자가 본인 확인 후 별도 검토하며 자동 계정 삭제 기능은 제공하지 않습니다. `DATA_REQUEST`는 자동 계정 삭제가 아니라 관리자 검토 요청입니다. 로컬 Chrome 저장소는 사용자가 Chrome 또는 확장 데이터를 삭제할 때까지 남고, GitHub 커밋은 GitHub 설정에 따라 관리되어 커뮤니티 철회로 자동 삭제되지 않습니다. 백업의 보관 기간·삭제 시점은 확인하지 않은 상태이므로 단정하지 않습니다. GitHub Issues에는 원본 코드, 계정 인증 정보, 개인정보를 올리지 마세요.
