# CodeArchive 데이터 처리 안내 초안

최종 게시용 개인정보처리방침으로 확정되기 전의 구현 안내입니다. 출시 전 운영자의 비공개 문의·삭제 요청 수단과 서버·로그·백업의 보관 기간을 확정해야 합니다. 현재 구현에 없는 계정 삭제 기능이나 확정되지 않은 보관 기한을 약속하지 않습니다.

## 처리하는 정보

- 본인 정답 풀이의 원본 코드, 플랫폼·문제 번호·제목·주소, 언어, 결과, 제출 식별자와 시각, 제공되는 실행시간·메모리·코드 길이.
- GitHub 로그인에서 제공된 계정 ID·닉네임·프로필 이름·이메일·아바타. GitHub에서 제공하지 않는 항목은 없을 수 있습니다.
- 테마·내보내기 설정, 연결된 GitHub 저장소·브랜치·경로, 자동 커밋 선택, 커뮤니티 공개 설정, 동기화·커밋 작업 상태.
- 공개 풀이에 대한 좋아요와 댓글.
- 계정 확인 및 동기화 요청을 인증하는 연결 정보. GitHub/OAuth 인증 정보는 서버에서 처리하며 브라우저의 로그인 쿠키 값은 확장이 읽지 않습니다.

사이트 결과와 제출 목록에서 필요한 정보를 확인합니다. 정답으로 확인되지 않은 코드나 다른 사용자의 제출은 본인 풀이로 수집하지 않습니다. 전체 방문 기록, 다른 사이트의 문서, 비밀번호 입력란을 수집하지 않습니다.

## 사용 목적과 저장

풀이 조회·검색·코드 표시, 중복 제출 확인, 수집 중단 후 복구, 서버 동기화, 선택한 GitHub 저장소에 기록, 사용자가 정한 커뮤니티 공개와 댓글·좋아요에 사용합니다.

Chrome 프로필 내부의 IndexedDB와 확장 저장소에는 풀이 기록과 재시도 정보를 보관합니다. 로그인한 계정의 신규 정답은 자동 동기화합니다. 전송 실패 시 내부 기록을 유지하고 다시 시도합니다. 과거 수집은 로그인 없이 시작할 수 있으며 서버 동기화와 GitHub 일괄 커밋은 관리 화면에서 실행합니다. Chrome 종료 중에는 확장 작업이 진행되지 않습니다.

GitHub 로그인과 서버 동기화에 CodeArchive API를 사용합니다. 연결된 GitHub 저장소에 대한 커밋은 자동 커밋 ON 또는 명시적인 수동 커밋 요청에 따라 처리합니다. 저장소의 공개·비공개 상태는 GitHub 설정에 따릅니다. CodeArchive에서 공개를 취소해도 이미 GitHub에 커밋한 코드는 자동 삭제하지 않습니다.

## 커뮤니티 공개

새 정답의 기본 공개 설정은 공개이며 설정에서 비공개를 선택할 수 있습니다. 공개한 코드, 닉네임과 풀이 성능 정보는 같은 플랫폼·문제의 풀이를 공개한 로그인 사용자에게 표시됩니다. 공개된 풀이에는 좋아요와 댓글을 남길 수 있습니다.

개별 공개를 취소할 수 있습니다. 중복 제출 공개 방식을 변경하면 기존 정답 풀이에도 즉시 적용되며, 전체 공개 또는 실행시간·메모리·코드 길이 기준의 한 제출 공개를 선택합니다. 상대방이 이미 복사한 코드나 GitHub 기록까지 회수하지는 않습니다.

## 정보 관리와 현재 제한

관리 화면에서 계정 로그아웃, GitHub 자동 커밋 ON/OFF, 풀이 공개 설정을 변경할 수 있습니다. 확장 삭제 또는 Chrome 프로필 데이터 삭제는 로컬 기록을 지울 수 있으며 서버 기록이나 GitHub 커밋을 자동 삭제하지 않습니다.

계정 및 서버 기록의 삭제 요청, 접근·정정 요청, 보관 기간과 백업 삭제 범위는 게시 전 운영 절차와 비공개 문의 수단을 함께 확정합니다. GitHub Issues에는 원본 코드, 계정 인증 정보, 개인정보를 올리지 마세요.
