# 정올 신규 정답 제출 저장 누락 — #367

## 실제 관찰과 원인

2026-10-06 Chrome 정올 #5187에서 사용자가 다시 제출한 정답창을 확인했다. 결과는 정답100점/288ms/47,908MB였다. 현재 compact sheet는 `role=dialog`, `aria-modal=true`, `aria-label=정답이에요!`, `aria-describedby=dialog-desc-2`, `data-dialog-id=2`로 표시되며 h2와 aria-labelledby가 없다. 기존 parser가 h2 제목만 허용해 정답 결과를 감지하지 못했다. 제출 감지와 에디터 동기화는 확인되었다. 코드와 인증정보는 기록하지 않았다.

## 수정

- 기존 h2 제목 모달과 compact aria-label 모달을 모두 지원한다.
- 동일 dialog의 숫자 ID와 description 연결, 정확한 정답 제목과100점/성능 정보, 표시 상태와 닫기 버튼을 검증한다. 중복 성공 모달/잘못된 연결/오답/숨김/충돌한 제목은 거절한다.
- 현재 제출 snapshot과 새 결과 비교/검증, 저장 성공 응답 후1회 소비는 기존 동작을 유지한다.
- 정올에도 기존 비민감 page-local 진단 단계(snapshot/결과 대기/저장 응답)를 표시한다. 코드/계정/ID/오류 원문은 포함하지 않는다.
- 확장0.2.4 릴리스. 기존 설치 폴더는 build.local.json 경로에 백업 후 갱신한다. 확장 관리 새로고침 및 이미 열린 문제 탭의 새로고침이 필요하다.

## 검증 범위

- 실제 정답창 DOM 관찰과 합성 회귀 테스트를 구분한다. 단위 테스트는 원본 제출 저장의 실제 Chrome 검증을 대체하지 않는다.
- 새 빌드 적용 후 실제 제출 저장 확인/사용자 검증 전 Issue를 닫지 않는다.
- Netlify 배포는 사용자 요청대로 수행하지 않는다. 기존 데이터 변환/누락된 과거 제출 임의 업로드는 수행하지 않는다.
