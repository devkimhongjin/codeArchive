## 에이전트 전달 규칙

1. 기획 → 구현: 승인된 요구사항/인수 조건과 범위 변경 이력을 전달한다.
2. 구현 → 검증: `implementation-handoff.md`를 작성하고 정확한 커밋/변경 파일을 고정한다.
3. 검증 → 구현: 실패는 요구사항 ID, 재현 명령, 실제 결과와 함께 반환한다.
4. 검증 → 기록: 최종 판정, KPI 측정값, 장애와 미검증 범위를 전달한다.
5. 요구사항 해석이나 범위가 바뀌면 구현·검증 에이전트가 임의로 결정하지 않고 기획으로 돌려보낸다.
