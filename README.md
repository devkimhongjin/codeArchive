# CodeArchive

코딩테스트 문제 풀이 기록을 자동화하는 Chrome Extension 프로젝트입니다.

## 목표

- SWEA 문제 정보 및 제출 코드 자동 기록
- 기존 풀이 수동 추가
- AI 활용 수준 기록
- 소스 파일 및 Markdown 내보내기
- Notion 및 GitHub 연동

## 기술 스택

- Chrome Extension Manifest V3
- TypeScript
- Vue 3
- Vite
- IndexedDB
- Chrome Storage API

## 지원 예정 플랫폼

1. SWEA
2. 프로그래머스
3. 정올
4. LeetCode
